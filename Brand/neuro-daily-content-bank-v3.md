## Blueprint Rules

**Hook Format — Premis + Trigger:**
```
Premis:  [situasi familiar — maks 7 kata]
Trigger: [fakta mengejutkan / reframe — maks 7 kata]
```
1. Tidak ada kata penghubung antara premis dan trigger
2. Bahasa sehari-hari — "bikin" bukan "menyebabkan"
3. Trigger harus bisa dibaca sambil scroll, tanpa baca ulang
4. CTA wajib bisa dijawab dalam 1–3 kata
5. Hashtag wajib: `#neurosains #produktivitas` + topik spesifik
